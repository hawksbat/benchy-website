# Benchy Design System

## Direction
Premium Windows software site: restrained, factual copy, real Benchy screenshots, and controlled dark surfaces.

## Tokens
- Orange: `#FA643F`
- Deep backgrounds: `#121212`, `#161616`, `#1A1A1A`
- Surfaces: `#1E1E1E`, `#232323`, `#292929`
- Text: `#F5F5F5`, secondary `#A6A6A6`, muted `#737373`
- Success: `#4BC77D`

## Layout
The main container is capped at 1240px. Desktop sections alternate text and real product screenshots. Mobile layouts stack text before media and never create horizontal scrolling.

## Components
Buttons have primary, secondary, and text variants. Screenshots use 16px corners, subtle borders, dark shadows, and a restrained orange halo behind the image. Navigation and FAQ use accessible vanilla interactions with Preline loaded for compatible behavior.

## Motion
IntersectionObserver reveals use opacity and transform only. Reduced motion removes transitions. Gallery changes fade and translate by 6px.

## Copy
Use short, factual French-first copy. Do not invent prices, FPS, versions, users, or product claims.
